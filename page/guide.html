Panduan Praktis Verifikasi Keamanan File

Pelajari perintah utilitas Linux, PowerShell Windows, serta cara membaca output terminal untuk membongkar penyamaran berkas berbahaya secara mandiri.

1. Mengatasi Ekstensi Ganda & Memeriksa Magic Bytes

Jangan percaya begitu saja pada nama file di layar. Di Linux, gunakan perintah berikut untuk membongkar tipe MIME biner asli:

$file --mime-type Dokumen_Penting.pdf
Ket: file --mime-type adalah perintah utama, ganti Dokumen_Penting.pdf dengan nama file yang ingin diperiksa.
✅ Contoh Output Jika File PDF Asli: Dokumen_Penting.pdf: application/pdf
🚨 Contoh Output Jika Menyamar (Berisi .EXE): Dokumen_Penting.pdf: application/x-dosexec
🔬 Perintah Lanjutan: Membaca Kode Hex & ASCII (Magic Bytes) Secara Langsung

Ingin membuktikan langsung isi byte pertama file seperti pada tabel kamus di bawah? Gunakan perintah xxd atau hexdump berikut untuk menampilkan **8 byte pertama** dalam format **Hex** sekaligus **Karakter ASCII**-nya:

$xxd -g 1 -l 8 Dokumen_Penting.pdf
Ket: Opsi -g 1 memisahkan tiap 1 byte Hex, dan -l 8 membatasi pembacaan hanya pada 8 byte pembuka (header). Alternatif jika tidak ada xxd: hexdump -C -n 8 namafile.
✅ Output Hex & ASCII Dokumen PDF Asli: 00000000: 25 50 44 46 2d 31 2e 37 %PDF-1.7
🚨 Output Hex & ASCII Malware Menyamar Jadi PDF: 00000000: 4d 5a 90 00 03 00 00 00 MZ......
🪟 Alternatif di Windows PowerShell (Tanpa Install Aplikasi Tambahan):
PS>Format-Hex -Path .\Dokumen_Penting.pdf | Select-Object -First 1
💻 Contoh Output PowerShell Format-Hex: 00000000 25 50 44 46 2D 31 2E 37 0A 25 D0 D4 C5 D8 0A 31 %PDF-1.7.%ÔÄÅØ.1

2. Pemeriksaan Integritas Checksum SHA-256

Validasi keaslian file unduhan dari internet dengan membandingkan nilai sidik jari digital SHA-256:

$sha256sum Patch_Update_v2.zip
Ket: sha256sum adalah perintah utama, ganti Patch_Update_v2.zip dengan nama file unduhanmu.
💻 Contoh Output Terminal Linux (64 Karakter Hexadecimal): e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855 Patch_Update_v2.zip
⚡ Trik Cepat Linux: Bandingkan Hash Otomatis Tanpa Cek Satu-Satu

Malas mencocokkan 64 karakter dengan mata telanjang? Gunakan perintah echo yang digabung dengan sha256sum -c untuk menyuruh Linux memvalidasi kecocokannya secara otomatis:

$echo "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855 Patch_Update_v2.zip" | sha256sum -c -
✅ Output Jika Hash 100% Cocok (Asli): Patch_Update_v2.zip: OK
🚨 Output Jika File Sudah Dimodifikasi/Trojan: Patch_Update_v2.zip: FAILED
sha256sum: WARNING: 1 computed checksum did NOT match
🪟 Perintah Cek SHA-256 di Windows PowerShell:
PS>Get-FileHash .\Patch_Update_v2.zip -Algorithm SHA256
💻 Contoh Output PowerShell: Algorithm Hash Path
--------- ---- ----
SHA256 E3B0C44298FC1C149AFBF4C8996FB92427AE41E4649B934CA495991B7852B855 C:\Downloads\Patch_Update_v2.zip

3. Manajemen Hak Akses Linux (Permission Check)

Cabut izin eksekusi yang tidak wajar pada dokumen pasif menggunakan perintah chmod:

$chmod -x file_mencurigakan.pdf
Ket: chmod -x mencabut atribut eksekusi (x) sehingga file tidak bisa berjalan sebagai program.
🔍 Memeriksa Status Permission Sebelum & Sesudah dengan ls -lh:
$ls -lh file_mencurigakan.pdf
🚨 Sebelum (Berbahaya - Ada Huruf 'x'): -rwxr-xr-x 1 mhs mhs 1.9M Nov 4 09:15 file_mencurigakan.pdf
✅ Sesudah chmod -x (Aman - Pasif): -rw-r--r-- 1 mhs mhs 1.9M Nov 4 09:15 file_mencurigakan.pdf
⚡ Mengatasi Awareness Fatigue (Sapu Bersih Banyak File di Flashdisk):

Saat menghadapi puluhan file di flashdisk teman, jangan periksa manual satu per satu. Gunakan perintah find berikut untuk langsung mendeteksi berkas mana saja yang diam-diam memiliki izin eksekusi program:

$find . -maxdepth 1 -type f -executable
🚨 Contoh Output (Langsung Menangkap 3 File Jebakan di Tengah Tumpukan): ./Data_Kuisioner_User.xlsx.vbs
./Poster_Kegiatan_Kampus.jpg
./Invoice_Sewa_Hosting.pdf.exe

4. Menampilkan Ekstensi Asli & Audit Cepat di Windows

Secara bawaan (default), Windows menyembunyikan ekstensi file yang sudah dikenal sehingga Kontrak_Magang.pdf.exe hanya terlihat sebagai Kontrak_Magang.pdf. Buka kedoknya lewat pengaturan GUI atau perintah PowerShell berikut:

  • Windows 11: Buka File Explorer → Klik menu View di atas → Pilih Show → Centang File name extensions dan Hidden items.
  • Windows 10: Buka File Explorer → Klik tab View → Centang kotak File name extensions.
🪟 Perintah PowerShell untuk Melacak File Berekstensi Ganda di Folder Downloads:
PS>Get-ChildItem -File | Where-Object { $_.Name -match '\..+\.(exe|vbs|bat|scr|cmd|ps1)$' }
🚨 Contoh Output PowerShell (Mendeteksi File Berekstensi Ganda): Mode LastWriteTime Length Name
---- ------------- ------ ----
-a---- 04/11/2026 13:10 1945600 Kontrak_Magang_2026.pdf.exe
-a---- 04/11/2026 13:12 28672 Form_Pengajuan_Beasiswa.docx.vbs

5. Membedah Isi Teks Tersembunyi (Strings) & Privasi VirusTotal

Penyerang sering menyisipkan perintah powershell, URL webhook pencuri data, atau skrip tersembunyi di akhir file gambar (.jpg). Di Linux, kamu bisa mengintip teks yang bersarang di dalam file biner tanpa membukanya dengan perintah strings:

$strings Denah_Ruangan_Kantor.jpg | grep -iE "http|powershell|cmd|\.exe|eval"
🚨 Contoh Output Jika Gambar Mengandung Payload Tersembunyi: powershell.exe -NoProfile -WindowStyle Hidden -EncodedCommand JABzAD0ATgBlAHcALQBPAGIAag...
https://malicious-c2-dropper.example.com/steal_cookie.php

💡 Tips Privasi VirusTotal: Jangan pernah mengunggah dokumen pribadimu langsung ke situs pemindai publik. Gunakan Local Static File Inspector di Beranda FileMate untuk menyalin kode SHA-256-nya saja, lalu cek reputasi hash tersebut di VirusTotal dengan aman!

6. Prosedur Darurat & Perintah Isolasi Jika Terlanjur Klik Malware

Apabila kamu tidak sengaja mengeksekusi berkas crack/patch atau lampiran yang memicu malware, lakukan 3 langkah penyelamatan darurat (First Response) ini dalam 60 detik pertama:

  1. Putuskan Koneksi Internet Seketika: Matikan Wi-Fi atau cabut LAN agar infostealer gagal mengirim session cookies browser ke server peretas (C2 Server).
  2. Lacak & Hentikan Proses Asing: Periksa proses mencurigakan dan koneksi jaringan gelap yang aktif menggunakan perintah di bawah ini.
  3. Rotasi Password & Cabut Sesi dari HP: Gunakan perangkat lain yang bersih (HP) untuk mengganti password akun utama dan pilih Logout from all devices.
🛑 Perintah Terminal untuk Melacak & Mematikan Proses Malware di Linux:
$ps aux --sort=-%cpu | head -n 6
🚨 Contoh Output (Terlihat Proses Cryptominer/Stealer dengan PID 4812): USER PID %CPU %MEM VSZ RSS TTY STAT START TIME COMMAND
mhs 4812 94.5 2.1 412900 44120 ? Sl 13:18 1:42 /tmp/.update_dependency_miner
$kill -9 4812
Ket: Ganti angka 4812 dengan nomor PID proses berbahaya yang ingin kamu hentikan paksa.
